## 一、Privacy practices（隐私权规范）标签页

### 1. Single purpose（单一用途）

```
DIC explains a word, abbreviation or phrase on a web page in the context of the sentence it appears in. When the user rests the pointer on a word or selects text, DIC shows a small popup next to it with an explanation generated by Google's Gemini API using the user's own API key.
```

### 2. Permission justification（权限理由）

后台会按 manifest 逐项列出，对应填写：

**storage**

```
Stores the user's own Gemini API key and their preferences (trigger mode, dwell time, explanation language, model name) on the device with chrome.storage.local, and caches recent explanations in chrome.storage.session so the same lookup is not requested twice. Nothing in storage is sent to the developer.
```

**Host permission: https://generativelanguage.googleapis.com/***

```
This is the only remote host DIC contacts. The extension's service worker calls Google's Gemini API at this host to generate the explanation, and to verify the user's API key on the setup page. The user supplies their own API key; requests go directly from the browser to Google.
```

**Content scripts on all sites (http://*/*, https://*/*, file://*/*)**

后台可能把它显示为 "Host permission" 或 "Site access" 的理由框：

```
DIC is a reading aid that must work on whatever page the user is reading; the user cannot know in advance which sites will contain unfamiliar terms, so a fixed list of sites would defeat the single purpose. The content script only (1) detects which word is under the pointer or selected, (2) reads the sentence and up to 800 characters of surrounding text from the same paragraph, and (3) renders the explanation popup in a Shadow DOM. It does not read or transmit page URLs, titles, whole pages, form fields, passwords or browsing history, and it ignores text inside input fields and editable areas. It makes no network requests itself; all requests are made by the service worker to the single host above. activeTab was considered and rejected because the feature is triggered by hovering, with no toolbar click.
```

### 3. Remote code（远程代码）

选 **No, I am not using remote code**。

```
All JavaScript is packaged in the extension. DIC does not load or execute any remotely hosted code. The Gemini API returns JSON text only, which is rendered with textContent (never innerHTML or eval).
```

### 4. Data usage（数据使用）勾选

| 类别 | 勾选 | 原因 |
|---|---|---|
| Personally identifiable information | 否 | 扩展本身不收集姓名、邮箱等。预约表单在扩展之外，由隐私政策说明 |
| Health information | 否 | |
| Financial and payment information | 否 | 目前没有收款。开通付费后要重新评估 |
| Authentication information | **是** | 用户的 Gemini API Key 保存在本地，并作为凭据发给 Google。保守起见按"是"披露 |
| Personal communications | 否 | |
| Location | 否 | |
| Web history | 否 | 不读取、不发送网址或浏览记录 |
| User activity | 否 | 鼠标位置只在本地用来判断停在哪个词上，不记录、不发送 |
| Website content | **是** | 会把用户查的词、所在句子和前后最多 800 个字符发给 Google Gemini |

三条声明全部勾选（都符合事实）：

- I do not sell or transfer user data to third parties, outside of the approved use cases
- I do not use or transfer user data for purposes that are unrelated to my item's single purpose
- I do not use or transfer user data to determine creditworthiness or for lending purposes

### 5. Privacy policy URL

填 `store/privacy-policy.html` 发布后的公开网址。发布前先把文件里的 `CONTACT_EMAIL` 换成一个你愿意公开的联系邮箱。

## 二、Test instructions（给审核员的测试说明）

这一项很重要：DIC 需要 API Key 才能用，审核员没有 Key 就什么都看不到，很可能因此判定"功能无法验证"。建议专门建一个只给审核用的 Key 填在这里，审核通过后在 AI Studio 里删掉。

```
DIC needs a Google Gemini API key to work (bring-your-own-key; no account with us).

1. After install, the setup page opens automatically (or click the DIC toolbar icon).
2. Paste this test key into the input box in step 3: <PASTE A TEST KEY HERE>
   The page shows "已连接 Gemini ✓" (Connected to Gemini).
3. On the same page, a sample English paragraph appears. Rest the pointer on a word such as "covenants" or "leverage" for about half a second. A popup appears next to the word with an explanation in Chinese.
4. Move the pointer into the popup to load a deeper explanation and follow-up questions. Click the speaker icon to hear the word. Press Esc to close.
5. It works the same way on any web page, e.g. https://en.wikipedia.org/wiki/Private_equity

The UI language is Simplified Chinese because the product explains English text to Chinese-speaking readers. No sign-in is required and no data is sent to the developer.
```

## 三、Store listing（商店页面）

**Category**：Education（或 Productivity）
**Language**：Chinese (Simplified)

**Description（中文，面向用户）**

```
读英文资料时遇到不认识的词、缩写或术语，把鼠标停在上面，DIC 就在原位告诉你它在这句话里是什么意思。不用切换标签页，不打断阅读。

· 结合上下文解释：同一个词在金融和半导体语境里意思不同，DIC 读的是你正在看的这句话
· 深入理解：把鼠标移进弹窗，自动补充背景、相关概念和可以继续追问的问题
· 朗读：点小喇叭听发音，再点一次慢速
· 轻量：不用注册账号，装上三步配置即可使用

使用前需要一个你自己的 Google Gemini API Key（可免费申请），安装后的引导页会带你完成。

隐私：DIC 没有自己的服务器。查词时，这个词、所在句子和少量上下文会用你的 Key 直接发给 Google Gemini；不发送网址和整页内容，开发者收不到任何数据。

DIC 目前免费使用，2027 年 1 月 18 日起收费。Google API 的使用费用由 Google 决定，不包含在内。
```

**Description（English，可放在中文之后，方便审核员阅读）**

```
DIC explains unfamiliar English words, abbreviations and terms in the context of the sentence you are reading. Rest the pointer on a word and a small popup explains what it means here, in Simplified Chinese. No tab switching.

Requires your own Google Gemini API key (free to create); the setup page walks you through it in three steps. DIC has no server: lookups go directly from your browser to Google's Gemini API, and the developer receives no data.
```
